# Portfolio personal

Sitio estático para presentar tus proyectos de GitHub, tecnologías y aprendizaje actual.

## Personalización

1. En `script.js`, `githubUsername` está configurado como `frvargasu`. Tus repositorios públicos con contenido se cargan automáticamente; edita `stack` y `featuredProject` cuando cambien tus tecnologías y proyectos.
2. La sección de aprendizaje presenta Power BI, DAX, Power Query, Copilot e inteligencia artificial como tecnologías en curso, no como experiencia laboral.
3. La tarjeta de presentación usa una ilustración de código en vez de una fotografía personal.

Abre `index.html` en un navegador para ver el sitio. Los proyectos de GitHub requieren conexión a internet.
